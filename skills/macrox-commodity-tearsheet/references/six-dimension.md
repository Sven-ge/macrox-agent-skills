# 六维分析框架 · 商品品种 Tear Sheet

> 权威来源：本文件。每维必须独立成段，结论必须回答 so what。

## H1 · 价格处于什么阶段

**问题**：近端价格处于趋势的哪一段？对交易者意味着什么？

- 数据：overview 现价/涨跌；日线近 60–120 日高低点、均线相对位置（用返回序列描述，勿臆造均线公式若未算）。  
- 推理：排除至少一种替代解释（如「不是单边下跌，因为…」）。  
- 结论：一句话阶段定性 + 置信度。

## H2 · 期限与基差在定价什么

**问题**：近远月结构、基差隐含了怎样的供需/持有成本预期？

- 数据：`struct_get_term`、`struct_get_basis`。  
- 推理：contango/backwardation、基差强弱与价格阶段是否同向。  
- 结论：结构偏好（紧平衡/宽松等）——用可观察结构语言，不写内部模型分。

## H3 · 库存与仓单节奏

**问题**：仓单/库存代理指标在累库还是去库？

- 数据：`struct_get_warehouse`（窗口对比）。  
- 推理：与价格、基差是否背离。  
- 结论：库存节奏一句话 + 置信度。

## H4 · 持仓与资金行为（能取则取）

**问题**：多空持仓比与席位是否显示拥挤或单边增仓？

- 数据：`struct_get_position_ratio`；若有 `ticker` 则龙虎/会员排名。  
- 无合约时：明确「本维仅持仓比，无席位明细」。  
- 结论：资金行为观察（描述性，不做隐秘信号）。

## H5 · 舆情与近端催化剂

**问题**：近期信息流主线是什么？哪些事件可能驱动波动？

- 数据：`factor_get_sentiment`、快讯/搜索。  
- 列出 ≥3 条催化剂（日期 + 标题级事实）；无则写资讯稀疏。  
- 结论：近端叙事主线。

## H6 · 风险与情景

**问题**：什么会证伪当前叙事？三种情景如何表述？

- 风险清单 ≥3（宏观、结构、流动性/交割、政策等，需与前面数据挂钩）。  
- 情景表 Bull / Base / Bear：每格写「可观察条件」+「对价格/结构的含义」，**禁止**编造精确目标价。
