# HTML 模板 · macrox-industry-chain-map

单文件 HTML。文件名：`macrox-chain-{chain_id}-{period_end}.html`。

## 区块顺序

1. 顶栏：MACROX INDUSTRY CHAIN · `{chain_name}` · 时间窗  
2. Hero：title / dek / 3 bullets  
3. **环节目录表**：stage · 品种 · 现价 · 涨跌 · 基差/期限/仓单（skipped 显示 —）  
4. **代理 KPI**：每条规则一句话 + 读数  
5. **库存节奏**  
6. **政策冲击** 列表（日期 + 作用环节）  
7. 页脚：MacroX MCP · 代理指标非内部定价模型 · 不构成投资建议 · data_gaps  

## 视觉

浅底、金线 `#C9A227`，无紫渐变。最大宽约 920px。表格优于长文。
