# 板块契约 · 对齐终端 futures-report

栏目顺序与终端详情页一致，**不得增删一级栏目**。空栏目保留标题并写「未取到」。

正文由模型根据本次 `data` 撰写；数字必须能指回工具。资讯归纳含义，禁止标题流水账，也禁止另起「深度研报」章节。

## 早报（morning）

| 顺序 | 栏目 | 写什么 |
| --- | --- | --- |
| 0 | Hero | 一句定调（板块强弱 + 主因类型）。其下四段：**【盘面】【驱动】【关注】【风险】**，各 1–3 句。 |
| 1 | 市场 KPI | 只放本次能从截面算出的：上涨/下跌家数、涨跌中位数、成交量/持仓量比等。没有官方「多空比」「放量品种数」算法就不要填，标未取到。 |
| 2 | 主力合约涨跌榜 | 涨幅端 + 跌幅端各若干行（建议各 6）。品种名、合约、现价、涨跌幅来自 overview；**驱动**一列用快讯/盯盘一句话，无则空，禁止编。 |
| 3 | 隔夜要闻 | 4–8 条。早报优先 `news_list_intel time_range=session`（上一交易日 18:00 后）。时间 + 压缩后的含义，可点品种。 |
| 4 | 异动雷达 | 来自 `watch_get_ranks`。品种 + 指标/摘要；无品种的记录丢弃或进 gaps。 |
| 5 | 今日关注 | 气泡/短标签，来自高重要度快讯或热榜主题，**不编日程**。 |

## 晚报（evening）

| 顺序 | 栏目 | 写什么 |
| --- | --- | --- |
| 0 | Hero | 同早报四段，口径改为**日盘收后**。 |
| 1 | 市场 KPI | 同早报，用日盘截面。 |
| 2 | 盘后亮点 | 2–4 个主题块（如「结构 · 黑色」）。先结论后 2–4 句证据；原料=涨跌榜 + 基差截面 + 可选席位。 |
| 3 | 异动速览 | `watch_get_ranks` 表：类型 / 品种 / 摘要。 |
| 4 | 席位变化 | 最多 3 个合约。先 `seat_get_contract_position_chg` 选标的，再对 ticker 调龙虎/会员。无 ticker 则整栏未取到。 |
| 5 | 基差与期限 | `struct_get_basis view=market_snapshot`；可补 `struct_get_term view=market_overview`。表格：品种 / 结构 / 近月基差率。 |
| 6 | 新闻时间线 | 日盘窗口快讯 4–8 条（`time_range=today`）。 |
| 7 | 明日关注 | 短标签，来自已取快讯/热榜；不编未出现的会议。 |

## 措辞

- 三态分开：事实（据数据）/ 估算（说明口径）/ 推断（「可能/通常」）。  
- 综合看法只给偏强/偏弱/震荡 + 观察点。不荐股、不目标价、不下单指令。  
- 禁止把 KPI 公式、工具名、JSON 键写进读者正文（页脚/脚注可写工具名）。
