# HTML 模板 · macrox-report-studio

文件名：`macrox-report-{morning|evening}-{as_of}.html`。

1. 顶栏：`MACROX REPORT STUDIO · {morning|evening} / {as_of} · 原料生成`  
2. Hero 标题 = `hero.conclusion`；其下四段盘面/驱动/关注/风险  
3. 市场 KPI（缺项显示未取到）  
4. 按 `sections.md` 输出其余栏目（早报：榜、要闻、雷达、今日关注；晚报：亮点、异动、席位、基差、时间线、明日关注）  
5. data_gaps / unresolved_names  
6. 页脚：MCP 原料生成稿 · 不是终端已发布刊物转排 · 不构成投资建议  

浅底、金线 `#C9A227`。榜单与 KPI 用紧凑表。最大宽约 840px。涨跌色按国内习惯红涨绿跌。
