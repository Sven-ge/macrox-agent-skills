# QA 清单 · macrox-report-studio

派生稿通过本清单才能交付。

- [ ] 原文来源工具与 id/日期写在页眉  
- [ ] 章节顺序与原文小标题对应，未擅自增删论点  
- [ ] 品种索引中每个 `symbol` 经过 `ref_list_symbols` 或原文明确代码  
- [ ] 每个索引品种有「稿内表述」与「现况脚注」（现况来自 MCP；失败则「未取到」）  
- [ ] 数字冲突只加脚注/高亮，**不改写**原结论句  
- [ ] 无新增目标价、无把 QA 写成新的投资建议  
- [ ] 页脚免责 + 数据来源 MacroX MCP  

冲突标记用语：`【现况核对】稿内…；截至 {as_of} MCP …（工具 …）`。
