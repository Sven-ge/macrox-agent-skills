# QA 清单 · macrox-report-studio

生成稿通过本清单才能交付。

- [ ] 页眉写明 `morning|evening`、`as_of`、**原料生成**（不是刊物 id）  
- [ ] 一级栏目与 `sections.md` 一致，未另开栏目、未删空栏  
- [ ] Hero 含一句定调 + 盘面/驱动/关注/风险；结论能在榜单或快讯中找到证据  
- [ ] 所有价格、涨跌幅、家数、基差、席位数字来自本次 MCP `data`，否则「未取到」  
- [ ] 未使用 `report_get_paper` 的 hero/answer/榜单/要闻作为底稿  
- [ ] 关注/明日标签未编造 MCP 未出现的会议或数据发布  
- [ ] 无目标价、无下单指令  
- [ ] 页脚免责 + 数据来自 MacroX MCP 原始工具
